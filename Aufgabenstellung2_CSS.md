# Aufgabe 2: CSS - Steckbrief gestalten

## Ziel

In dieser Aufgabe wirst du den HTML-Steckbrief aus Aufgabe 1 visuell anpassen. Mit CSS bestimmst du zum Beispiel Farben, Schriftarten und Abstände.

### 2.1 CSS mit HTML verbinden

Erstelle im gleichen Ordner wie deine HTML-Datei eine Datei mit dem Namen `style.css`. Damit deine CSS-Anpassungen im Browser angezeigt werden, musst du sie mit dem HTML verbinden. Das machst du im `<head>`-Bereich deiner HTML-Datei:

```html
<link rel="stylesheet" href="style.css">
```

### 2.2 Gestalte deinen Steckbrief

Schreibe deine CSS-Regeln in `style.css`. Eine CSS-Regel besteht aus einem Selektor ("Welche Elemente sind von dieser Regel betroffen?") und den Eigenschaften, die du ändern möchtest:

```css
h1 {
  color: blue;
}
```

Mit diesem Code setzt du die Schriftfarbe für alle Überschriften des Typs `H1` auf Blau.

Gestalte mindestens diese Elemente:

- Ändere die Hintergrundfarbe der Webseite.
- Wähle eine Schriftart und eine Textfarbe.
- Gestalte die Überschrift.
- Verändere Abstände, damit die Inhalte gut lesbar sind.

Speichere beide Dateien und lade die Webseite im Browser neu. Probiere verschiedene Werte aus und beobachte, was sich verändert.
