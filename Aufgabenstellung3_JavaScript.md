# Aufgabe 3: JavaScript - Steckbrief interaktiv machen

## Ziel

In dieser Aufgabe ergänzt du deinen Steckbrief aus Aufgabe 1 und 2 um eine interaktive Funktion. Mit JavaScript kann eine Webseite auf Aktionen wie einen Mausklick reagieren.

### 3.1 Füge einen Button ein

Ergänze in deiner HTML-Datei im `<body>` einen Button:

```html
<button id="grussButton">Sag Hallo</button>
```

### 3.2 Verbinde JavaScript mit HTML

Erstelle im gleichen Ordner eine Datei mit dem Namen `script.js`. Verbinde sie am Ende des `<body>`-Bereichs mit deiner HTML-Datei:

```html
<script src="script.js"></script>
```

### 3.3 Reagiere auf einen Klick

Schreibe JavaScript in `script.js`, damit beim Klick auf den Button eine Begrüssung angezeigt wird. Teste deine Webseite im Browser.

Wenn du fertig bist, kannst du eine weitere Funktion ausprobieren: Lass den Button zum Beispiel den Text auf der Webseite ändern.
